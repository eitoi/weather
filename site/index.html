Run these in Terminal on your Mac. Or double-click Agent Web.command in the WeatherAgent folder.

Startcd ~/weather/WeatherAgent && .venv/bin/python web.py
Start in backgroundcd ~/weather/WeatherAgent && nohup .venv/bin/python web.py >> data/web.log 2>&1 &

Settings

The Outlook and Avalanche data refresh by themselves every hour. The Weather map's HRRR data is fetched only when you press ↻, which needs a token. Use a fine-grained token with only Actions: Read and write on this repository; it is stored only in this browser.

Data: NOAA HRRR (3 km, every 25 mb), NAM 3 km nest, RAP 13 km, earlier HRRR runs; long range from ECMWF, GFS, ICON, GEM, UKMO and GEFS/ECMWF ensembles via Open-Meteo; NWS Salt Lake City discussion. Avalanche tab: avalanche center ratings from avalanche.org, NRCS SNOTEL, and an HRRR-based estimate elsewhere.
